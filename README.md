# Реестр протоколов — локальная версия

Статический сайт. Записи и распознавание остаются на устройстве: сайт не подключается к API, облачной базе, шрифтам или CDN. В проекте нет демонстрационных записей.

## Запуск в Windows

1. Скачайте/клонируйте весь репозиторий, включая `data` и `vendor`.
2. Откройте PowerShell в папке проекта и выполните:

   `powershell -ExecutionPolicy Bypass -File .\start-local.ps1`

3. Сайт откроется по адресу `http://127.0.0.1:8765/`. Сервер слушает только loopback-интерфейс этого компьютера. Для остановки нажмите Ctrl+C в окне PowerShell.

Локальный HTTP-сервер нужен браузеру для запуска WebAssembly OCR worker. Он не принимает соединения из интернета и не отправляет данные наружу.

## Где хранятся записи

Реестр сохраняется в `localStorage` браузера на этом устройстве и в этом профиле. Очистка данных сайта в браузере удалит записи. Между устройствами записи не синхронизируются. Фото протокола используется только в памяти страницы при распознавании и не сохраняется в реестре.

## Локальное распознавание

Tesseract.js 5.1.1, Tesseract.js-core 5.0.0 и языковые модели `rus`/`eng` находятся в `vendor/` и `data/`. После получения проекта интернет для работы сайта и OCR не требуется. OCR может ошибаться — проверьте извлечённые поля по фото.

Сторонние компоненты и языковые модели распространяются по лицензии Apache-2.0.
